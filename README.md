# waps-wellbet-pages

本仓库用于归档和发布多个独立的 HTML 页面。这些页面不针对任何单个域名或具体网站，仅作为静态页面资源存储与展示使用。

## 项目简介

waps-wellbet-pages 是一个通用的 HTML 页面归档仓库。仓库内包含若干独立编写的 HTML 文件，内容涉及不同的展示主题或功能模块。所有页面均为静态资源，无需后端服务即可直接通过浏览器查看。

## 目录说明

- `pages/`：存放所有归档的 HTML 页面文件。
- `assets/`：存放页面引用的静态资源，例如样式表、图片、字体等（如有）。
- `docs/`：存放与该仓库或页面相关的文档说明（如有）。

## 页面归档说明

- 每个 HTML 页面均独立完整，不依赖外部动态数据源。
- 页面之间无交叉引用或依赖关系。
- 归档页面可能不定期更新，但历史版本保留在提交记录中。
- 不保证所有页面在特定浏览器或设备上的兼容性，建议使用现代浏览器查看。

## 维护说明

- 本仓库由维护者不定期更新，添加新的 HTML 页面或修正现有页面。
- 不接收外部贡献或拉取请求，仅供个人归档与发布使用。
- 如发现页面显示异常或链接失效，请通过仓库 Issues 反馈，但不保证及时修复。

## 使用方式

你可以通过以下方式查看仓库中的页面：

1. 克隆本仓库到本地，在浏览器中直接打开 `pages/` 目录下的 HTML 文件。
2. 使用 GitHub Pages 功能（如已启用）在线访问归档页面。
